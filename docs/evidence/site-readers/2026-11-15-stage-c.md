## Found and fixed on the way (`c3e93c3`)

1. `site_read` didn't exist for main: OpenClaw refuses plugin tools that the manifest doesn't declare
   (`contracts.tools`). Declared.
2. The checker let a bare `evil.test` through (it knew only some endings). It now removes any bare
   `name.ending`; unit tests keep "J.Novák", "s.r.o.", "p. 32", times and dates.
3. The reader calls `tool_describe` to learn its tool; the guard had blocked it. `tool_search` and
   `tool_describe` are now allowed for the reader (they change nothing).
4. The site browser now keeps HOME in its own profile folder (`jorah-sites` has no home).
5. Test harness only: OpenClaw looks a host name up before navigating, so the fake school's name
   resolves (via `/etc/hosts`) only while the test runs; the sign-out switch now reaches the fake
   school; commands run from `/tmp`; only the test's own processes are stopped; Chrome's automatic
   `/favicon.ico` isn't counted as the reader opening a page.
