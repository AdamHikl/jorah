# Run log

One file a day, `YYYY-MM-DD.md`, appended to by each run and by Jorah. Never rewritten.

Each run adds:

```markdown
## Run <run id> (<HH:MM>)

- **Did:** <T-xxxx and what happened to each>
- **Found:** <what was learnt, with paths or sources>
- **Tier reached:** written | built | tested in simulation | tested on hardware
- **New:** <questions Q-xxxx, Adam tasks A-xxxx, backlog items T-xxxx>
- **Problems:** <what failed or blocked, or nothing>
- **Next:** <what the next run should pick up>
```

Evidence tiers stay separate. A tier not reached isn't claimed.
